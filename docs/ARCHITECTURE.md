# معماری دموی وب‌سایت گروه صنعتی سپنتا (GitHub Pages Flagship Demo)

## مسیرهای دمو (Static Export Ready)
1. `/` — صفحه اصلی ترکیبی (Split Hero پرسونامحور + آمار کارخانه ۱۳۸۰/۱۰۰۰ واحد + Bento محصولات ۷گانه + اسلایدر Before/After + مقایسه تعاملی uPVC vs ترمال بریک + گالری پروژه‌ها + CTA ارسال نقشه)
2. `/products/` — کاتالوگ کامل ۷ خط تولید سپنتا با فیلتر زنده (بر اساس خوشه، جنس، کاربرد) و کارت‌های دارای نمایش مقطع فنی SVG
3. `/configurator/` — استودیوی برآوردگر هوشمند قیمت و پیکربندی زنده SVG + سبد استعلام پروژه (Quote Cart) + چاپ پیش‌فاکتور
4. `/projects/` — گالری پروژه‌های اجراشده قابل فیلتر (زنجان و سراسر ایران) + بخش تعویض بدون تخریب
5. `/about/` — معرفی کارخانه، خط تولید با ظرفیت ۱۰۰۰ عدد در ماه، گواهینامه‌ها و ضمانت ۱۰ تا ۲۵ ساله + فرم ارسال نقشه و تماس

## منطق مهندسی کانفیگوریتور هوشمند (`/configurator/`)
- **پشتیبانی از محصولات قابل پیکربندی:** پنجره دوجداره uPVC، آلومینیوم ترمال بریک، شیشه بالکنی تاشو، توری کشویی.
- **پیش‌نمایش زنده SVG:** تغییر هم‌زمان ابعاد (نسبت عرض به ارتفاع)، تعداد لنگه (۱ تا ۴ لنگه + گزینه کتیبه بالا)، علامت‌های استاندارد جهت بازشو (ثابت، تک‌حالته، دوحالته، کشویی، تاشو) و رنگ فریم (سفید `#F8FAFC`، آنتراسیت `#1E293B`، شامپاینی `#B8A389`، طرح چوب بلوطی `#8B5A2B`).
- **اعتبارسنجی مهندسی لحظه‌ای:**
  - عرض مجاز کل: `40` تا `600` سانتی‌متر | ارتفاع مجاز کل: `40` تا `400` سانتی‌متر.
  - اگر عرض هر لنگه بازشوی لولایی از `100cm` یا ارتفاع از `220cm` بیشتر شود ← نمایش هشدار نرم مهندسی (پیشنهاد افزودن کتیبه، افزایش تعداد لنگه یا تغییر به سیستم کشویی/ترمال بریک).
  - اگر مساحت تک‌قاب از `3.2` مترمربع بیشتر شود ← پیشنهاد هوشمند شیشه سکوریت یا لمینت ایمنی.
  - تبدیل خودکار اعداد فارسی/عربی ورودی کاربر به اعداد انگلیسی در منطق محاسبه (`inputMode="numeric"`).
- **بازه برآورد مهندسی (نه قیمت قطعی):** محاسبه بازه ±۸٪ بر اساس متراژ، نوع پروفیل، شیشه، رنگ، توری و نوع نصب (نوساز / تعویض بدون تخریب / تحویل کارخانه) + نمایش شفاف توضیح «برآورد مهندسی اولیه؛ قیمت قطعی پس از بررسی نقشه یا اندازه‌گیری نهایی».
- **سبد استعلام پروژه (`Quote Cart`):** ذخیره خودکار در `localStorage` برای افزودن چند پنجره با ابعاد مختلف، امکان آپلود/پیوست نام فایل نقشه (شبیه‌سازی در دمو) و دکمه «خروجی چاپی / پیش‌فاکتور».
